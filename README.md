# Efstathios Outas · evolvlabs

I build tools for running AI models on your own GPUs, and I work on making open models better at Greek. Based in Greece. More at [evolvlabs.dev](https://evolvlabs.dev).

## Main projects

| Project | What it is |
|---|---|
| [Forge](https://github.com/Efs-O/Forge) | VS Code coding agent for your own models: full llama.cpp/GGUF control, 60+ agent tools, undo any turn, no telemetry. On the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Efsoo.forge-llm) and Open VSX. |
| [HalluScribe](https://github.com/Efs-O/halluscribe) | Local-first archive and search for your AI coding sessions (Rust + Tauri), with an MCP server so agents can recall earlier sessions. |
| [NemotronGR](https://github.com/Efs-O/NemotronGR) | Case study: a Greek LoRA fine-tune of NVIDIA Nemotron 3 Nano 30B-A3B on 44 GB of consumer GPUs, natively on Windows. Weights on [Hugging Face](https://huggingface.co/Efso/Nemotron-3-Nano-30B-A3B-GR). |
| [Gemma4GR](https://github.com/Efs-O/Gemma4GR) | Greek fine-tune of Gemma 4 E4B, and JOY, an open Greek Piper TTS voice. |
| [Gemma4kids](https://github.com/Efs-O/Gemma4kids) | Offline coding teacher for kids, powered by Gemma 4: plain English in, HTML animations out. |

## Smaller tools

- [CacheWarden](https://github.com/Efs-O/CacheWarden): keeps Claude Code's prompt cache warm.
- [forge-relay](https://github.com/Efs-O/forge-relay): a coordination board for Claude Code and Codex agents working in one repo.
- [HalluMeter](https://github.com/Efs-O/Hallumeter): a desktop ring that warns when an AI session's context window is filling up.
- [airos-wakebot](https://github.com/Efs-O/airos-wakebot): wake a PC from Telegram, with the bot running on a Ubiquiti radio.

Everything is built and tested on a Windows workstation with 2× RTX 5060 Ti and an RTX 3060.
